 # finchGE Example Project - SantaFe Trail Problem

The Santa Fe Trail problem (often called the Artificial Ant problem)
is a classic benchmark in the field of Genetic Programming (GP).
It was popularized by John Koza in the early '90s
to test how well an algorithm can evolve a "program" to solve a navigation task.

This project was generated using the finchGE as an example of Control Problem to demonstrate
basic usage of FinchGE benchmarks for control problems.

Read more about FinchGE at [finchge.readthedocs.io](https://finchge.readthedocs.io)
